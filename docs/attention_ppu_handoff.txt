Attention contracts
-------------------
* Public entry points: group_query_attention_GQA, multi_query_attention_mqa,
  swin_transformer_attention, adaptive_attention_span.
* GQA/MQA: Q[B,Hq,Lq,D], K/V[B,Hkv,Lk,D]; MQA requires Hkv=1.
* GQA/MQA/Adaptive masks use ordinary right-aligned broadcasting. Boolean True
  allows attention; floating masks add to scores. A per-batch mask must include
  the singleton head axis, for example [B,1,Lq,Lk]. A 3D mask is per-head.
* Swin Q/K/V are already projected and partitioned as [windows,N,C] or
  [B,nW,N,C]. Window size accepts Ws, [Ws], or [Wh,Ww]. This operator computes
  window attention. Boolean True blocks attention. Relative bias is [H,N,N].
* Adaptive uses upper-left causal alignment, distance x=i-j, hard constraint
  0<=x<=max_span, and weight clamp((span+ramp_length-x)/ramp_length,0,1).
  Zero weights are excluded, and the remaining probabilities are renormalized.
  span[H] or span[B,H] is clamped to [0,max_span]; 0<=max_span<=Lk is enforced.
* Fully masked rows return zeros. Noncontiguous tensor strides are supported.
* FP32 dot uses IEEE precision; FP16/BF16 use FP32 softmax/accumulation.
* QK, scaling, mask/bias/span, softmax, and PV are fused. Tile helpers are
  inlined. Selected short-Q/long-KV GQA/MQA cases use partial and merge kernels.

MoE contract
------------
Gate and expert weights are explicit inputs. Supported expert modes are
identity, linear, relu, gelu, silu, swiglu, and geglu. The returned output has
exactly hidden_states.shape and includes expert computation and weighted combine.
expert_indices always remain in [0,E). Dropped routes have zero weights;
surviving routes are renormalized. See the full document before integration.

Latest MQA low-precision results and kernel details: docs/mqa_low_precision_tuning.txt.

Latest MoE low-precision expert results: docs/moe_low_precision_tuning.txt.

Representative-shape follow-up: see docs/operator_shape_coverage.txt.
MQA/Swin/Adaptive/MoE now each use 20 selected parameter sets. The original
small-shape performance snapshot below predates that selection; GQA is unchanged.

Validated PPU results
---------------------
Final source versions are covered by passing correctness batches: GQA 153,
MQA 133, Swin 113, Adaptive 113, MoE 152: 664 distinct parametrized cases total.
This total describes coverage across batches, not a single combined pytest run.
The native MoE benchmark reference also matched the independent CPU reference
for all seven expert modes and three dtypes (21 additional comparisons).
Targeted pre-commit checks passed for the 18 changed source/test/config files.

Core benchmarks completed 420 records: 120 each for GQA/MQA (masked and
unmasked), and 60 each for Swin, Adaptive and MoE. Each scenario has 20 shapes
and FP16/BF16/FP32. Timings compare against the local PyTorch reference in each
benchmark. Speedup is reference latency divided by FlagGems latency.
Geometric means, with equal weight per shape:
                                    FP16      BF16      FP32
GQA without mask                    0.978x    0.975x    1.008x
GQA with mask                       2.291x    2.324x    0.971x
MQA without mask                    0.979x    0.987x    1.029x
MQA with mask                       2.519x    2.544x    0.999x
Swin                                3.226x    3.479x    1.148x
Adaptive                            6.407x    6.416x    3.198x
MoE (mixed expert modes)            2.395x    2.404x    1.836x

These are PPU results only, not guarantees for every shape or another backend.
Swin uses an isolated full rerun with warmup=10, iter=50; the other four use
warmup=5, iter=20. The first Swin run had timing outliers; its raw results are
retained in the validation archive. Adaptive now uses max_span=Lk, correcting
earlier out-of-contract cases; those earlier timings are different workloads.

MetaX verification
------------------
Use the configured MetaX PyTorch and Triton/FlagTree environment and follow the
repository setup instructions. Confirm FlagGems detects the MetaX backend.

MACA_VISIBLE_DEVICES=0 PYTHONPATH=src OMP_NUM_THREADS=4 pytest -q tests/test_group_query_attention.py tests/test_multi_query_attention.py tests/test_swin_transformer_attention.py tests/test_adaptive_attention_span.py tests/test_moe_gate_top_k_routing.py

MACA_VISIBLE_DEVICES=0 PYTHONPATH=src OMP_NUM_THREADS=4 pytest -q -s benchmark/test_group_query_attention.py benchmark/test_multi_query_attention.py benchmark/test_swin_transformer_attention.py benchmark/test_adaptive_attention_span.py benchmark/test_moe_gate_top_k_routing.py --level core --warmup 10 --iter 50

For compilation failures, retain the shape/dtype/strides, compiler version, and
error. Retest the same references and shape set after backend-specific changes.
Current launch policies were measured on PPU; different compiler lowering,
shared-memory limits or register allocation may require platform-specific tuning.
